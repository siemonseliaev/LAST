# CLI-приложение для анализа зависимостей (Этап 1: минимальный прототип и конфигурация)

Минимальное CLI-приложение на Python (версии 3.11 и выше), предназначенное для инициализации и конфигурации параметров анализа пакетов и их зависимостей.

## Описание проекта

На данном этапе реализации приложение выполняет следующие задачи:
1. Загружает параметры конфигурации из файла `config.toml` с использованием встроенного модуля `tomllib`.
2. Проверяет наличие всех обязательных параметров, а также корректность их типов данных.
3. Проводит валидацию значений (проверка на отрицательные числа, корректность режимов работы).
4. Выводит список успешно загруженных параметров или сообщает об ошибках валидации.

---

## Настраиваемые параметры

В конфигурационном файле (`config.toml`) должны быть заданы следующие обязательные параметры:

| Параметр | Тип | Описание | Допустимые значения / Пример |
| :--- | :--- | :--- | :--- |
| **`package_name`** | `str` | Имя анализируемого пакета | Например: `"requests"` |
| **`repo_url`** | `str` | URL-адрес репозитория или путь к файлу | Например: `"https://github.com/psf/requests"` |
| **`repo_mode`** | `str` | Режим работы с репозиторием | `"online"`, `"offline"`, `"test"` |
| **`package_version`** | `str` | Версия анализируемого пакета | Например: `"2.31.0"` |
| **`output_image`** | `str` | Путь/имя результирующего файла изображения | Например: `"output_graph.png"` |
| **`max_depth`** | `int` | Максимальная глубина анализа зависимостей | Целое число $\ge 0$|

---

## Установка и запуск

1. **Клонирование репозитория или скачивание файла проекта в одной директории**

2. **Создание конфигурационного файла `config.toml`** в корневой папке проекта, как пример содержимого `config.toml`:
   ```toml
   package_name = "sample-package"
   repo_url = "[https://github.com/example/repo](https://github.com/example/repo)"
   repo_mode = "online"
   package_version = "1.0.0"
   output_image = "graph.png"
   max_depth = 3
